# 知识库实现方案（2026-11-27）

需求来源：方哥 2026-11-27 确认的 Demo（公司电脑 `~/Desktop/Personal/Fdesign设计稿/vibeboss-知识库/final/index.html`）。

## 要解决的事

把各种格式的资料（PPT、Word、Excel、Markdown、HTML）归到一处；同一份资料的多个版本（早会版、技术评审版）放在一起；名字由小模型按规则定，不由人定；问智能体时能很快找到；可以一键同步到飞书；对话里可选是否加载。

## 三个核心决定

1. **知识库就是一个普通文件夹**。默认 `~/VibeBoss/Knowledge`，也可以指向任何文件夹。文件保持原格式，不进数据库。
2. **索引是文件夹里的一份 `索引.md`**，每个文件一行（路径、类型、给谁、一句话摘要），同一主题的各版本排在一起、最新在前。智能体先读这一份再按路径开原文件。不做向量库：个人知识库几百到一两千个文件，一份索引读得完，命中靠规范的名字和摘要。
3. **整理由小模型做，每次都能撤销**。命名规则“主题-版本-日期”，目录“分类/分组/文件”。模型给出的每个字段都经过校验（只能落在知识库内、分类只能选已有的），答得不对的文件留在“待整理”，不会被移走。每次整理记一条记录，撤销就是把文件搬回原处、改回原名；撤销过的文件不会被自动再整理。

VibeBoss 自己的记录放在文件夹里的 `.vibeboss/knowledge.json`（每个文件的主题、版本、原名和操作记录）；文件夹位置和整理模型放在 VibeBoss 数据目录的 `vibeboss/knowledge.json`。

## 分四步

| 步  | 内容                                                                       | 状态           |
| --- | -------------------------------------------------------------------------- | -------------- |
| 1   | 文件夹设置、扫描、自动整理与撤销、索引、知识库页面、侧栏入口、整理模型选择 | 已做（本分支） |
| 2   | 对话里加载知识库：输入区开关、选分类、设为项目默认                         | 已做（本分支） |
| 3   | 同步到飞书：由带飞书 MCP 的智能体执行，页面显示待同步、进度和中断续传      | 待做           |
| 4   | 更新情况与热力图                                                           | 已做（本分支） |

### 第 2 步的做法（已做）

输入区模型选择旁的知识库控件决定这个会话是否加载、加载哪些分类，可设为项目默认。加载后，服务端每次把用户消息发给智能体时，在提示里附一句说明（知识库位置、先读 `索引.md`、只用哪些分类）。这句话只有智能体看得到，不出现在用户发出的消息里，也不改各家智能体的系统提示。

### 第 3 步的做法（方哥 2026-11-27 同意）

服务端不直接调飞书接口。点“同步”时开一个子会话，把待同步文件清单交给装了飞书 MCP 的智能体；它每传完一个，就把飞书链接和时间写回 `.vibeboss/knowledge.json`。页面按这份记录显示进度，中断后再点一次只传剩下的。HTML 演示插入飞书文档，其余作为文件上传。

## 这次没做、需要知道的

- 新文件要打开知识库页面才会被整理（没有后台监听文件夹）。
- 网页版（非桌面应用）不能拖文件进来，只能把文件放进文件夹。
- PDF 和超过 16 MB 的 Office 文件读不了正文，只按文件名整理。
- 一次最多整理 30 个文件，多的下次打开页面接着整理。
- 手机端没有知识库页面。

# 豆包工作预设智能体

- 需求：添加提供方 › ACP 列表里能直接选「豆包工作」，图标用本机豆包工作 App 的 logo 灰色版，和其他注册表智能体一致。
- 做法：新增 `apps/web/src/components/settings/acpLocalPresets.ts`（VibeBoss 本地预设，当前只有豆包：`~/Library/Application Support/doubao_cli/app/current/doubao acp serve`）；`AcpRegistrySearchStep.tsx` 列表顶部渲染预设行（行布局抽成 `AgentRow` 共用）；`AddProviderInstanceDialog.tsx` 点添加即填好本地命令并跳到命名步骤。
- 图标：`Icons.tsx` 的 `DoubaoIcon` 是从 DoubaoWork.app 图标抠出的透明遮罩，跟随文字颜色变灰。本地实例按可执行文件名 `doubao` 识别（手动配的也算），图标键借用 `acpRegistryAgentId` 槽位（`vibeboss-preset:doubao`）。
- 服务端：`AcpRegistrySupport.ts` 解析本地命令时展开开头的 `~/`。
- 前提：用户需先 `doubao login`，否则状态显示未认证。
- 上游注意：`ProviderInstanceIcon.tsx`、`providerInstances.ts`、`ProviderInstanceCard.tsx` 的本地 ACP 图标分支冲突时保留 `acpLocalPresetIconKey` / `acpLocalPresetForIconKey`。

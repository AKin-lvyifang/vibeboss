# 项目记忆（第一版）

- 需求：记忆原来都存在各家智能体自己那里，按文件夹记、三家互相看不到、界面里看不到也改不了。现在每个项目有一份所有智能体共用的项目记忆，主控负责写，成员只读，用户在项目设置里能看、能改、能撤销。参考 `AKin-lvyifang/codex-memory-lite` 的分层和“现状可覆盖、决策只追加”，不照搬它的钩子和后台整理。设计定稿：`~/Desktop/Personal/Fdesign设计稿/vibeboss-项目记忆/final/index.html`。
- 做法：
  - 记忆是项目文件夹里的 `.vibeboss-memory/`：`current.md`（现状）、`decisions.md`（决策）、`spec/`（项目规范，可分文件夹）、`tasks/`（任务）、`archive/`（归档）。在工作副本里开的会话也写回项目主目录。
  - 项目的第一个主控会话自动建好记忆；项目里有 `.codex-memory/` 时照搬一份（current、spec、archive 原样，每个任务文件夹合成一份任务），旧文件夹不动。
  - 每轮发给智能体的提示里附一段 `<project_memory>` 说明（不出现在用户消息里）。会话的第一轮带文件清单和现状全文，之后只带一句提醒。主控被告知什么时候写、写到哪、不记什么；成员被告知只读、结论交回主控。
  - 主控用两个工具写：`project_memory_write`、`project_memory_archive`。服务端检查路径只能在记忆文件夹内、单个文件不超过 64KB、智能体写决策只能往后追加；成员调用会被拒绝。
  - 每次改动记一条更新记录（谁、来自哪个会话、改了什么），连同改之前的内容存在数据目录的 `vibeboss/memory/<项目哈希>.jsonl`，保留 90 天，可撤销；之后又改过的文件不能单独撤销那一条。
  - 界面：侧栏项目行鼠标移上去出现脑子图标（项目还没有记忆时淡显），点它进项目设置的“项目记忆”。模块里现状、决策各一行，项目规范按文件夹展开，任务可新建、归档；点一行在右侧抽屉看全文、编辑。“最近更新”显示 5 条，更多点“全部更新记录”进下一页。设置搜索能搜到“项目记忆”。
- 顺手修的：知识库说明原来只在“这一轮本来就有别的待发送上下文”时才拼进提示，普通轮次发不出去。现在两段说明在决定是否拼接之前先算好，有说明就走拼接路径。
- 复用 T3：RPC 和权限、MCP 工具通道（`McpToolAccess.actsAsCaller`、会话专用工具标注）、提示拼接（`withInlineContext`）、设置页分区和搜索定位（`#project-memory`）、右侧抽屉 `Sheet`、`ChatMarkdown`、打开文件夹 `shell.openInEditor`。

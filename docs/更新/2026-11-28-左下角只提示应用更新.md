# 左下角更新按钮只管 VibeBoss 本身

- 需求：左下角更新按钮原来把 Claude/Codex 等 CLI 和远程服务器的更新也合并提示（"全部更新"）。方哥要求这里只提示 VibeBoss 自己的版本更新；CLI 在 设置 › 智能体提供方 里各自更新。
- 做法：`apps/web/src/vibeboss.ts` 新增 `VIBEBOSS_SIDEBAR_APP_UPDATES_ONLY = true`。
  - `SidebarUpdatePill.tsx`：不再进入"全部更新"；手动点检查只查应用版本，不顺带查 CLI。
  - `SidebarChrome.tsx`：底部的 CLI 更新小条（SidebarProviderUpdatePill）不显示。
  - `SidebarUpdatePill.browser.test.tsx`："全部更新"那组测试在该开关下跳过。
- 自动检测：桌面端原有逻辑不变——启动 15 秒后检查一次，之后每 4 小时一次（`apps/desktop/src/updates/DesktopUpdates.ts`）。
- 上游注意：合并时保留上述三处开关判断；上游若新增 CLI 更新提示入口，同样按开关屏蔽。
- 已知：sidebar 目录下另有 14 个测试在改动前就失败（updateEverything.logic、Sidebar.browser 等），与本次无关。

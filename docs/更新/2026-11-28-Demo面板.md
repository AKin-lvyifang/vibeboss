# Demo 面板与 Capture 截图标注

- 需求：主控和其他智能体出的 1–3 份 Demo，放在右侧一个固定面板里比较；生成时有加载效果，做完点开就能在内置浏览器里标注；标注加一个“圈哪截哪”的截图模式。设计稿：`~/Desktop/Personal/Fdesign设计稿/vibeboss-Demo面板/claude/index.html`（方哥 2026-11-28 认可）。
- 做法：
  - 右面板新标签类型 `demo`，加号菜单里叫「Demo」，快捷字母 G，打开项目后可用。
  - 用工具交稿（方哥定，不用“约定文件夹”）：VibeBoss 工具通道多了三个动作（`mcp/toolkits/demo/`），Claude、Codex、Agy 在 VB 里都能用，不用装 Skill。
    - `demo_open`：开一格，返回格号和要写的 `page` 路径。`agent` 写谁做的（claude / codex / antigravity），面板据此配图标；`waiting: true` 表示排队；`newRound: true` 清掉上一轮。面板就是“一轮最多 3 份”，不分主稿、对比稿、定稿，那是各自工作流的事。
    - `demo_progress`：报进度 0–99；报得比上次小就当返工重来。
    - `demo_submit`：页面写完后交稿，格子变成缩略图。没写页面会被拒。
  - 只认工具交上来的：每个会话一个文件夹 `.vibeboss/demo/<会话 id>/<1|2|3>/`（会话 id 里的 `:` 等字符换成 `_`，否则 Windows 建不了），`status.json` 只由工具写。项目里原有的 HTML 一律不管。派出去的成员（如 @reviewer）开格子，会归到派它的主控会话下，进同一个面板。
  - 自动打开：界面看到本会话里一次 `demo_open` 刚完成（2 分钟内、没处理过），就打开 Demo 面板（`useDemoPanelAutoOpen.ts`）。别的会话出稿不会抢面板。不新加推送通道，也不在后台读文件。
  - 轮次：每次要新出 Demo 就开新一轮（`newRound`），一轮 1–3 份。第 4 份由工具拒收，提示开新一轮（方哥定）；在已有格子上改稿不算新增。
  - 不靠 Skill：各智能体共用的常驻说明（`packages/provider-core/src/server/orchestrationInstructions.ts` 的“Visuals and preview”一节）加了一条：用户要 Demo、原型或几个方案比较时，用这三个工具交稿。谁用 VibeBoss 都一样。
  - 不进交付物：`.vibeboss/` 开头的路径本来就不算交付物（`vibebossDeliverables.ts`），Demo 页不会混进交付物列表。
  - Esc 退回：Demo 网页里按 Esc（不在标注中、网页自己没接住），桌面端把它转给界面，界面切回 Demo 标签。只对从 Demo 面板打开的标签生效（`PickPreload.ts` 放行裸 Esc，`Manager.ts` 发 `vibeboss.demo.back`，`useDemoPanelAutoOpen.ts` 接收）。
  - 面板打开时读这三个状态文件：有没做完的每 1.5 秒读一次，全做完后每 5 秒一次；面板关着不读。服务端没有“监听文件夹”的接口，所以只能这样读。
  - 生成中：Animate UI 的 Glyph 字符背景，中间是 Animate UI 的进度条和百分比；每次报进度，数字和进度条一起用约 1.4 秒先快后慢地滚到新值（Animate UI 默认约 0.4 秒，看起来像直接跳过去）；每报一次进度，背景从中心荡出一圈。排队中只显示“等待中”。
  - 省资源：Glyph 加了两个 VibeBoss 参数，`burstMs`（平时静止，被进度涟漪或鼠标叫醒后只动 2.4 秒）和 `fps`（动的时候每秒最多 20 帧）。所以没有持续重绘。
  - 做完：卡片里是页面缩略图（沙箱 iframe，按 1280 宽缩放，加载方式和文件预览的 HTML 一样）。点卡片或按 1/2/3 用内置浏览器打开，带原生标注；再点同一份会回到已开的标签，Demo 改过版本会关掉旧标签再开新的。
  - Capture：标注工具条加第五个模式 Capture（快捷键 C）。拖框只当区域，不选组件；只有截图框时按框精确裁剪，不留白、不带描边。
- 复用 T3：右面板标签体系、`projects.readFile`、`assets.createUrl`（workspace-file 签名链接）、`openFileInPreview`、预览标注与截图裁剪链路、`@animate-ui/react` 的 Progress 原语。

# 右侧卡片：分工、交付物常驻

- 需求：分工、交付物两栏做着做着就不见了。原因是右侧卡片内容超过窗口高度时，会从完整模式退到精简模式，这两栏连同服务器、所在电脑整栏隐藏。方哥要求一直能看到。
- 做法：沿用 T3 对服务器、定时任务等长列表的处理，量卡片高度时不计入这两栏，内容多了就在卡片里滚动。
- 改动文件：`apps/web/src/components/chat/VibeBossThreadTeam.tsx`（两栏加 `data-thread-team-panel` / `data-thread-deliverables-panel`），`apps/web/src/components/chat/ThreadDetailsCard.tsx`（量高度时排除这两个标记，上游文件只改这一行选择器）。
- 上游注意：合并上游时若 `ThreadDetailsCard.tsx` 的排除列表被改，把这两个标记补回去。

# 隐藏测试版里用不上的三项

- 需求：设置 › 测试版里的「访客链接」「Simlock 设备主机」「智能体反馈」在 VibeBoss 用不上，隐藏并保持关闭。
- 做法：`apps/web/src/vibeboss.ts` 新增 `VIBEBOSS_HIDDEN_SETTING_ROWS`（guest-links、simlock-hosts、agent-feedback）；`LabsSettingsPanel.tsx` 按它不渲染这三行；`settingsSearch.ts` 搜索结果按 id 过滤。
- 关闭：三项上游默认就是关（false / off），隐藏后用户无法再打开，无需改服务端。
- 复用 T3：沿用已有的 `VIBEBOSS_HIDDEN_SETTINGS` 过滤思路，只是粒度从整页细到单行。
- 上游注意：合并时 `LabsSettingsPanel.tsx` 的 Beta 列表若冲突，保留三处 `VIBEBOSS_HIDDEN_SETTING_ROWS.has(...)` 判断；上游改了这几行的 id 要同步更新集合。

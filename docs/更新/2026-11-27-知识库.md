# 知识库（第 1 步：整理与索引）

- 需求：把各种格式的资料归到一处，同一份资料的多个版本放在一起，名字由小模型按“主题-版本-日期”定，智能体一问就能找到。方案和后续三步见 [docs/claude建议/2026-11-27-知识库实现方案.md](../claude建议/2026-11-27-知识库实现方案.md)。
- 做法：
  - 知识库是一个普通文件夹（默认 `~/VibeBoss/Knowledge`）。新文件由小模型起名、归到“分类/分组/”下，每次整理记一条记录，可撤销；撤销过的文件不再被自动整理。
  - 文件夹里的 `索引.md` 每个文件一行，同主题的版本排在一起、最新在前，给智能体先读。VibeBoss 自己的记录在文件夹的 `.vibeboss/knowledge.json`。
  - 侧栏左上那排入口加「知识库」，页面在 `/knowledge`：按分类筛选、搜索、同主题版本归组、整理记录与撤销、整理模型选择、打开文件夹；顶部有文件数、本周更新数和近 26 周的更新热力图（`KnowledgeOverview.tsx`）。
  - 对话里加载：输入区模型选择旁有知识库控件（`VibeBossKnowledgeControl.tsx`），可开关、选分类、设为项目默认。加载后服务端在每次发给智能体的提示里附一句说明（知识库位置、先读索引、只用哪些分类），这句话不出现在用户的消息里。选择存在数据目录的 `vibeboss/knowledge-selections.json`。
  - 列表按“分类 → 分组卡片”排，每个文件一行只显示名字；多版本的主题是一行，可展开收起（`KnowledgeList.tsx`）。
  - 知识图谱（`KnowledgeGraph.tsx`）：点按钮展开，节点按“知识库 → 分类 → 分组 → 主题 → 文件”一个个长出来，稳定后停止重绘；文件超过约 560 个时只画到主题。
  - 同步飞书：页头按钮开一个预填好任务的新会话，由装了飞书 MCP 的智能体上传；任务说明在知识库的 `.vibeboss/feishu-sync-task.md`，同步记录在 `.vibeboss/feishu-sync.jsonl`，页面据此给文件标“已同步 / 有更新”。
  - 原生检索：每个文件的正文按页、工作表、标题切成短段存进知识库文件夹的 `.vibeboss/index.sqlite`（SQLite 全文检索，中文按两字切词；只在硬盘上，查的时候才读，删掉会自动重建）。VibeBoss 的工具通道多了 `knowledge_search`（返回命中的段落、位置和引用写法）和 `knowledge_read`（读一个文件的全文，PPT、Excel 也能读）。加载了知识库的会话，说明里改为让智能体用这两个工具并在回答里标来源。文件：`KnowledgeIndex.ts`、`KnowledgeSearch.ts`、`mcp/toolkits/knowledge/`。
  - 云端知识库（程小帮）：知识库页分“本地 / 云端”两个页签。云端页显示已添加的库（按私有、公开分组），“添加云端库”滑入二级页从目录里挑；目录由 Claude 用程小帮 MCP 的 `list-knowledge-bases` 拉取后写进数据目录的 `vibeboss/knowledge-cloud-catalog.json`，VibeBoss 自己不调程小帮。输入框的知识库菜单多了“云端”一段，只在 Claude 主控时可勾；勾选后给智能体的说明里列出库名和 ID，要求用 `search-knowledge` 并只搜这些库。“发布到云端”是三步页面：同步飞书（自动）、在程小帮控制台把飞书文件夹加为数据源（手动一次，用户自己标记完成）、云端库按周期更新（自动）。文件：`KnowledgeCloud.ts`、`KnowledgeCloud.tsx`、`useKnowledgeConversation.ts`。引用前缀统一为“本地”和“程小帮”。
  - 没把握就不答（2026-11-28，参考 XERJ）：问题先用系统自带的中文分词（`Intl.Segmenter`）拆成词，去掉疑问词和虚词；每段结果按“问题里的词它提到了多少”打分，少见的词分量重，知识库里根本没有的词分量最重。不到一半的段落不返回，所以资料里没有的问题会得到空结果，智能体被要求如实说“知识库里没有”。测试题加了 6 道“资料里没有答案”的陷阱题。
- 复用 T3：
  - 文档抽字用 T3 的 `documentTextWorker`（`__document-text` 子命令），但不在用户文件旁边写 `.txt`。
  - 小模型调用沿用规则检查的做法（`generateTranscriptionPostProcessing` + `reviewModelSelection`）。
  - 打开文件和文件夹用 `shell.openInEditor`；选文件夹用桌面端的 `pickFolder`。

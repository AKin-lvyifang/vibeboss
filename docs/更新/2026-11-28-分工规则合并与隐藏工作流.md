# 分工、规则合并为一个入口；隐藏工作流

- 需求：侧栏「分工」「规则」很相似，合并为「分工 & 规则」；实验功能里的「工作流」查清作用，没用就隐藏。
- 合并做法（第二版，方哥要求上下拼成一页）：侧栏一个入口「分工 & 规则」（/agents），页面上面是分工（主控 + 成员表），往下滑是规则（公共规则、主控规则、各家全局规则）。两块共用一份草稿，右上角一个按钮：有改动时叫「保存」（保存并同步规则文件），没改动但文件没同步时叫「同步规则文件」；成员名不合法时按钮不可点。/rules 自动跳到 /agents。
  - 文件：`AgentsPage.tsx` 改为 `RolesSection.tsx`（只剩两张表）；`RulesPage.tsx` 改为 `RolesRulesPage.tsx`（整页）；`routes/_chat.agents.tsx` 指向整页，`routes/_chat.rules.tsx` 改为跳转；删掉只给旧规则入口用的 `animate-ui/icons/scroll.tsx`；zh 里“点同步规则文件”的提示改为“点保存”。
  - 行为变化：以前分工页的「保存」只存配置，不写规则文件；现在保存会同时同步规则文件（成员名单本来就写在主控的规则文件里，改了分工也该同步）。
- 工作流（T3 Labs 功能，默认关）：用 TypeScript 脚本把多个智能体步骤、定时、webhook、等人确认串成一条可断点续跑的流程，脚本放 `~/.t3/workflows/`，主要用 `t3 workflow` 命令行启动。要写代码，VibeBoss 已有主控派活和定时任务，判断用不上 → 隐藏设置行（workflows-beta、workflow-skipped-runs）。开关关着时命令面板的「打开工作流」本来就不出现。
- 上游注意：上游若改 Labs 列表或 VibeBoss 侧栏导航，保留隐藏判断和单入口；`i18n:generate` 后要跑 `vp run vibeboss:rebrand`。

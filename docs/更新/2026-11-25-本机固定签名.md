# 本机固定签名（钥匙串不再反复弹窗）

- 需求：VibeBoss 读钥匙串 `gemini` 密钥时，点过「始终允许」仍反复弹窗。原因是 mac 包用临时签名（ad hoc），每次打包签名都变，钥匙串授权失效。
- 做法：本机登录钥匙串里放一张自签名代码签名证书「VibeBoss Local Signing」（10 年有效，已设为可信代码签名）。打包时检测到它就用它签名，否则退回临时签名（CI、别的电脑不受影响）。可用环境变量 `VIBEBOSS_MAC_SIGN_IDENTITY` 指定其他证书名，设为 `-` 强制临时签名。
- 复用 T3：electron-builder 的 `mac.identity` 配置，未签名分支原本就写 `identity: "-"`。
- 改动文件：`scripts/build-desktop-artifact.ts`（`resolveLocalMacSigningIdentity`）。
- 换电脑：新电脑没有这张证书时自动退回临时签名；需要时按同样方式在新电脑生成一张同名证书。
- 上游注意：合并上游时若 `createBuildConfig` 的 mac 签名分支被改，保留 `identity: resolveLocalMacSigningIdentity()`。
